## Limits

The real browser worker could not download its Pyodide modules from the configured external CDNs in this environment. Therefore a full live Pyodide computation was **not** verified here. The browser presentation tests replayed real native-engine responses through a test-only worker substitute; no substitute or fixtures are shipped in the application.

The native calculation smoke test used Random Forest on the bundled synthetic example. It does not establish XGBoost performance, validate all input formats or independently validate every optional scientific method. Optional-module responses were generated and rendered, including missing-input statuses where the example lacked necessary fields.

This release changes interface design, terminology, guidance, chart presentation and result lifecycle handling. Scientific fitting and physical calculation algorithms are retained. Carbon/footprint caches are now cleared when source/QC state changes. Exported report headings no longer expose development-phase labels.
